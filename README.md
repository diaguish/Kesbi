# Kës Bi

Application mobile de gestion financière pour commerçants et PME au Sénégal
(Android + iOS).

## Structure du repo
```
/mobile     App Flutter (Android + iOS)
/backend    API Django + DRF (déployée sur Render)
/docs       Documentation technique et ADR
```

## Démarrage rapide
Voir [docs/setup.md](docs/setup.md) pour l'installation complète.
